# LaundryNow：宿舍洗衣機即時狀態查詢系統

## 一、專案簡介

LaundryNow 是一個宿舍洗衣機即時狀態查詢系統，讓住宿生可以先在線上查看洗衣機目前是空閒、使用中或故障，也可以回報剩餘時間，減少白跑一趟。
