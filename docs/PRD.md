# LaundryNow 專題需求文件 PRD

## 專題名稱

LaundryNow：宿舍洗衣機即時狀態查詢系統

## 目標使用者

住宿學生，特別是需要共用宿舍洗衣機的學生。

## 核心問題

住宿生常常抱著衣服到洗衣間後，才發現洗衣機全部都在使用中，或是機器故障卻沒有明確標示，造成時間與體力浪費。

## 解決方式

建立一個網頁系統，讓住宿生可以在線上查看洗衣機目前是否空閒、使用中或故障，也可以回報剩餘時間與機器狀態。

## 功能需求

| 功能編號 | 功能名稱 | 功能描述 |
|---|---|---|
| F-01 | 查看洗衣機狀態 | 使用者可以查看所有洗衣機目前狀態。 |
| F-02 | 回報洗衣機狀態 | 使用者可以更新洗衣機狀態。 |
| F-03 | 設定剩餘時間 | 使用者可以輸入預估剩餘使用時間。 |
| F-04 | 新增洗衣機資料 | 使用者可以新增洗衣機編號與位置。 |
| F-05 | 編輯與刪除資料 | 使用者可以修改或刪除洗衣機資料。 |

## 非功能性需求

- 系統操作需快速。
- 表單避免空白輸入。
- 剩餘時間不可為負數。
- 介面需簡單清楚。
- 程式碼需方便維護。

## 範圍限制

- 不做登入註冊。
- 不連接真實洗衣機硬體感測器。
- 不做手機 App。
- 不做線上付款。
- 不做洗衣預約。
- 不做自動通知。

## 使用者故事

- 作為住宿生，我希望可以查看洗衣機是否空閒，避免白跑一趟。
- 作為住宿生，我希望可以看到剩餘時間，判斷是否要等待。
- 作為使用者，我希望可以回報洗衣機狀態，讓其他同學知道最新情況。
- 作為管理者，我希望可以新增、編輯與刪除洗衣機資料。

## 驗收標準

- 使用者可以看到洗衣機狀態列表。
- 使用者可以新增洗衣機資料。
- 使用者可以更新洗衣機狀態。
- 使用者可以輸入剩餘時間。
- 系統可以用顏色區分空閒、使用中、故障。
