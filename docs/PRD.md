# LaundryNow 專題需求文件 PRD

## 1. 專題介紹
LaundryNow：宿舍洗衣機即時狀態查詢系統，是一個提供住宿學生查詢宿舍洗衣機狀態的網頁系統。

## 2. 動機與背景
住宿生常常抱著衣服到洗衣間後，才發現洗衣機全部都在使用中，或是某台洗衣機故障卻沒有明確標示，造成時間與體力浪費。因此本系統希望讓使用者可以先在線上查看洗衣機狀態，減少白跑一趟。

## 3. 目標使用者
主要使用者為住宿學生，特別是需要共用宿舍洗衣機的學生。

## 4. 專題目標
- 查看洗衣機目前狀態
- 回報洗衣機狀態
- 設定剩餘使用時間
- 新增洗衣機資料
- 編輯與刪除洗衣機資料

## 5. 功能性需求

| 功能編號 | 功能名稱 | 功能描述 |
|---|---|---|
| F-01 | 查看洗衣機狀態 | 使用者可以查看所有洗衣機目前狀態 |
| F-02 | 回報洗衣機狀態 | 使用者可以更新洗衣機為空閒、使用中或故障 |
| F-03 | 設定剩餘時間 | 使用者可以輸入剩餘使用時間 |
| F-04 | 新增洗衣機資料 | 使用者可以新增洗衣機編號與位置 |
| F-05 | 編輯與刪除資料 | 使用者可以修改或刪除洗衣機資料 |

## 6. 非功能性需求
- 系統操作需快速
- 表單避免空白輸入
- 剩餘時間不可為負數
- 介面簡單清楚
- 程式碼需方便維護

## 7. 範圍限制
本次不包含：
- 使用者登入與註冊
- 真實洗衣機硬體感測器
- 手機 App
- 線上付款
- 洗衣預約
- 自動通知功能

## 8. 使用者故事
- 作為住宿生，我希望可以查看洗衣機是否空閒，避免白跑一趟。
- 作為使用者，我希望可以回報洗衣機狀態，讓其他人知道最新情況。
- 作為使用者，我希望可以查看剩餘時間，判斷是否要等待。

## 9. 驗收標準
- 使用者可以看到洗衣機狀態列表
- 使用者可以新增洗衣機資料
- 使用者可以回報狀態
- 使用者可以設定剩餘時間
- 狀態資料可以正確儲存
