# 組員分工 Work Division

## 規劃階段

規劃階段由全組一起完成：

- 專題主題與目標確認
- 功能清單與需求分析
- 系統架構與技術選型
- 畫面設計與 Wireframe / AI 預估畫面
- 週次時程與任務分配

## 實作階段分工

| 姓名 | 負責功能模組 | 對應功能編號 | 說明 |
|---|---|---|---|
