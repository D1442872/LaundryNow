# 畫面規劃 UI Plan

## 設計風格

LaundryNow 的畫面設計以簡潔、清楚、容易操作為主。使用卡片式設計呈現每台洗衣機狀態，並透過顏色快速區分不同狀態。

## 狀態顏色

| 狀態 | 顏色 |
|---|---|
| 空閒 | 綠色 |
| 使用中 | 橘色 |
| 故障 | 紅色 |

## 頁面規劃

### 首頁

- 網站標題：LaundryNow
- 副標題：宿舍洗衣機即時狀態查詢系統
- 標語：先查詢，再洗衣，減少白跑一趟的時間。
- 狀態統計區
- 洗衣機狀態卡片列表
- 新增洗衣機按鈕

### 新增洗衣機頁面

- 洗衣機編號
- 位置
- 初始狀態
- 剩餘時間

### 編輯洗衣機頁面

- 修改洗衣機編號
- 修改位置
- 修改狀態
- 修改剩餘時間

### 狀態更新區

- 空閒
- 使用中
- 故障
- 剩餘時間輸入欄位
