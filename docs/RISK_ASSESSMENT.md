# 風險評估 Risk Assessment

| 風險 | 發生可能性 | 影響程度 | 因應策略 |
|---|---|---|---|
| Flask 與 SQLite 連接不熟悉，導致資料無法正常儲存 | 中 | 高 | 先完成最基本的新增與查詢功能，再逐步加入修改與刪除功能。 |
| 使用者回報的狀態可能不準確 | 中 | 中 | 顯示最後更新時間，讓其他使用者判斷資訊是否仍可信。 |
| 組員功能整合時發生程式衝突 | 中 | 中 | 使用 GitHub 管理版本，並事先分配好不同功能模組。 |
| 時間不足，無法完成所有功能 | 中 | 高 | 優先完成核心功能：查看狀態、回報狀態、剩餘時間、新增資料。 |
