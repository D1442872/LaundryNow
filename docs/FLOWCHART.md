# 系統流程圖 Flowchart

## 查詢與回報洗衣機狀態流程

~~~mermaid
flowchart TD
    A[使用者進入首頁] --> B[系統讀取 SQLite 洗衣機資料]
    B --> C[顯示洗衣機狀態列表]
    C --> D[使用者選擇洗衣機]
    D --> E[使用者回報狀態]
    E --> F{狀態是否為使用中}
    F -- 是 --> G[輸入剩餘時間]
    F -- 否 --> H[剩餘時間設為 0]
    G --> I[更新資料庫]
    H --> I
    I --> J[更新最後更新時間]
    J --> K[回到首頁]
    K --> L[顯示最新狀態]
~~~

## 新增洗衣機資料流程

~~~mermaid
flowchart TD
    A[點選新增洗衣機] --> B[輸入洗衣機編號與位置]
    B --> C[選擇初始狀態]
    C --> D[輸入剩餘時間]
    D --> E{資料是否完整}
    E -- 否 --> F[顯示錯誤提醒]
    E -- 是 --> G[儲存到 SQLite]
    G --> H[回到首頁]
~~~
